# 🎬 Reels & TikTok Script Generator

> An automated CLI tool powered by **Anthropic Claude API** to generate high-retention, viral short-form video scripts for Instagram Reels, TikTok, and YouTube Shorts.

---

## 🌟 Key Features

- 🎯 **Scroll-Stopping Structure:** Every generated script follows a battle-tested structure: **Hook** (0-3s), **Body** (Value), **CTA**, **Caption/Hashtags**, and **Visual Suggestions**.
- 🎨 **Multi-Niche & Multi-Style:** Pre-configured context for Finance, Fitness, Mindset, Tech, Marketing, and General niches. Generates variations in Viral, Educational, Storytelling, and Motivational styles.
- ⚙️ **Flexible Workflow:** Run in full **interactive prompt mode** or pass commands directly via **CLI flags**.
- 📂 **Auto-Archiving:** Automatically exports generated script batches into clean, timestamped `.txt` files in the `scripts/` folder.
